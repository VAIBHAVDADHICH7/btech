# Exp 1: Study of LAN and Network Equipment
- **NIC (Network Interface Card)**: Layer 1/2 hardware with unique 48-bit MAC address.
- **Repeater & Hub**: Layer 1 devices (hub broadcasts frames to all ports, single collision domain).
- **Switch**: Layer 2 device forwarding frames via MAC address table (per-port collision domain).
- **Router**: Layer 3 device routing IP packets across subnets using routing tables.
- **Cabling**: Cat5e/Cat6 UTP (RJ-45, T568A/T568B straight-through vs crossover), Fiber Optic.
