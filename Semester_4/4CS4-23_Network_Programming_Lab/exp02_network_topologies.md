# Exp 2: Study & Verification of Standard Network Topologies
| Topology | Central Device | Fault Tolerance | Cost |
| :--- | :--- | :--- | :--- |
| **Star** | Switch/Hub | High (except central switch) | Moderate |
| **Bus** | Coax backbone + terminators | Low (backbone break stops all) | Low |
| **Ring** | Point-to-point loop | Low (dual-ring improves) | Moderate |
| **Mesh** | Full/Partial links | Very High | High |
