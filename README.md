# B.Tech CSE (8-Semester) Lab Code Repository (`btech`)

Complete lab programs organized by semester (`Semester_1` through `Semester_8`) following the RTU B.Tech CSE syllabus.

## Directory Structure
- `Semester_1/` — `1FY3-24` Computer Programming Lab (C)
- `Semester_2/` — `2FY3-24` Computer Programming Lab (C — Group B rotation)
- `Semester_3/` — `3CS4-21` DSA (C), `3CS4-22` OOP (C++), `3CS4-23` Software Engineering (Java/UML/SRS)
- `Semester_4/` — `4CS4-21` Microprocessor (8085 ASM), `4CS4-22` DBMS (SQL), `4CS4-23` Network Programming (C/NS2), `4CS4-24` Linux Shell (Bash), `4CS4-25` Core Java
- `Semester_5/` — `5CS4-21` Computer Graphics (C), `5CS4-22` Compiler Design (C/LEX/YACC), `5CS4-23` Analysis of Algorithms (C), `5CS4-24` Advance Java
- `Semester_6/` — `6CS4-21` Digital Image Processing (Python/OpenCV), `6CS4-22` Machine Learning (Python), `6CS4-23` Python Lab, `6CS4-24` Mobile App Development (Android Java)
- `Semester_7/` — `7CS4-21` IoT (Raspberry Pi/Python), `7CS4-22` Cyber Security (Python/HTML/JS/Guides)
- `Semester_8/` — `8CS4-21` Big Data Analytics (Java/Hadoop/Pig/Hive), `8CS4-22` Software Testing & Validation (Java/Selenium/Guides)
